# Kid Radd Russian translation — notes for Claude

See README.md for layout and workflow. Key rules:

- `kidradd/` is the English source. Don't hand-edit comic HTML. All Russian text lives in
  `translation/po/*.po`. `ru/` is generated by `tools/build.py` and git-ignored.
- Machine/Claude-drafted translations are saved **fuzzy**. The user reviews in Poedit and
  clears the flag. Never un-fuzzy an entry yourself.
- Keep every HTML tag from the msgid in the msgstr. Run `python tools/check.py` before committing.
- Run `python tools/render_check.py` after translating (Chromium is at
  `/opt/pw-browsers/chromium` in the cloud container: `CHROMIUM=/opt/pw-browsers/chromium`).
  Shorten lines that overflow. Bubbles are ~80 px wide × 3 columns at font size 2.
- Scope: comic pages only. Text baked into GIFs and non-comic pages are deferred.

## Translation style

- Names (fixed, in glossary.tsv; full list in translation/NAMES.md): Radd → Улёт, Sheena → Шина,
  Bogey → Бяка (male: masculine agreement — «бродячий Бяка», «Бяка сказал»), Gnarl → Отпад, Cool Ragnarok / C.R. / Seer → Отпадный Коллапс / О.Ко / Око
  (masculine, as «he» in the comic: «Око сказал»), Kobayashi the Discount Ninja →
  Кобаяси — копеечный ниндзя, Kielbasa (Radd's nickname) → Кулебяси, Captain QB → Капитан QB,
  GI Guy → Воин, Benny DaBunny → Зайка Бэнни, Lucky Penny → «Монетка на удачу»,
  Kid Radd (the game) → «Улёт-парень» (provisional; «Улёт» stays fixed, only «парень» declines: «Улёт-парню», «об Улёт-парне»;
  the hero's own name «Улёт» declines normally: «Улёта», «Улёту»). Use ё in Улёт.
- Addressing Dr. Amp: Sheena says «вы» until they leave Hopetown (comic211), «ты» after;
  Radd never says «вы» to anyone.
- Open naming questions live in translation/TODO.md.
- Tone: 90s cool-speak, but per character and context-dependent. When unsure, go neutral;
  the user polishes later.
- Russian typography: «ёлочки» for quotes, em dash — for dialogue breaks, … for ellipsis.
  Keep the English's ALL CAPS, bold and emphasis.
- Translator notes (`translation/notes/chNN.md`) are for puns, references and cultural
  context that the translation couldn't carry. Keep them short.
